# Sistema de Control de Estacionamiento — Examen Parcial II

Proyecto desarrollado para la gestión de vehículos, cálculo de tarifas y administración de registros en el sistema de estacionamiento utilizando PostgreSQL y pgAdmin.

---

## Tecnologías y herramientas

* **Base de Datos:** PostgreSQL
* **Administrador de BD:** pgAdmin 4
* **Entorno de Desarrollo:** IntelliJ IDEA
* **Control de Versiones:** Git & GitHub Desktop
* **Lenguaje:** SQL (DDL y DML)
